# 模板匹配方法说明

## 当前实际使用的方法

主程序实际运行时使用的是 `main.py` 中 `if __name__ == "__main__":` 内部定义的 `find_template()`。

核心算法：

```python
cv2.matchTemplate(main_img, template, cv2.TM_CCOEFF_NORMED)
```

也就是 OpenCV 的模板匹配方法：`TM_CCOEFF_NORMED`，归一化相关系数匹配。

该方法会在大图中滑动模板图，计算每个位置的相似度，最后通过：

```python
cv2.minMaxLoc(result)
```

取最高相似度 `max_val` 和对应左上角坐标 `max_loc`。

## 普通匹配流程

普通匹配用于部分旧逻辑和非严格识别。

流程：

1. 使用 `cv2.imread(template_path)` 读取模板图。
2. 使用 `cv2.matchTemplate()` 在截图中匹配模板。
3. 使用 `cv2.minMaxLoc()` 取最高相似度。
4. 如果 `max_val >= threshold`，认为匹配成功。
5. 返回：
   - `top_left`：模板左上角坐标
   - `center`：模板中心点坐标
   - `confidence`：最高相似度

默认阈值：

```python
threshold = 0.8
```

## 严格匹配流程

当前检测是否到达目标关卡时，使用严格匹配。

调用参数：

```python
find_template(
    screen_img,
    trigger_template_path,
    threshold=0.88,
    strict=True,
    edge_threshold=0.45,
    focus_threshold=0.82
)
```

严格匹配比普通匹配多做两层校验。

### 1. 灰度模板匹配

严格模式先把截图和模板都转成灰度图：

```python
main_match_img = cv2.cvtColor(main_img, cv2.COLOR_BGR2GRAY)
template_match_img = cv2.cvtColor(template, cv2.COLOR_BGR2GRAY)
```

然后仍然使用：

```python
cv2.matchTemplate(main_match_img, template_match_img, cv2.TM_CCOEFF_NORMED)
```

要求：

```python
max_val >= 0.88
```

### 2. 边缘匹配校验

如果灰度匹配通过，会截取匹配位置对应的灰度区域：

```python
gray_patch = main_match_img[y:y + th, x:x + tw]
```

然后对截图区域和模板分别做 Canny 边缘检测：

```python
patch_edges = cv2.Canny(gray_patch, 50, 150)
template_edges = cv2.Canny(template_match_img, 50, 150)
```

再用同样的模板匹配算法比较边缘图：

```python
edge_result = cv2.matchTemplate(patch_edges, template_edges, cv2.TM_CCOEFF_NORMED)
```

要求：

```python
edge_score >= 0.45
```

### 3. 左侧重点区域校验

严格模式还会取模板左侧 62% 宽度做二次匹配：

```python
focus_width = max(1, int(tw * 0.62))
focus_patch = gray_patch[:, :focus_width]
focus_template = template_match_img[:, :focus_width]
```

再进行：

```python
cv2.matchTemplate(focus_patch, focus_template, cv2.TM_CCOEFF_NORMED)
```

要求：

```python
focus_score >= 0.82
```

## 当前阈值汇总

| 用途 | 参数 | 当前值 |
|---|---:|---:|
| 普通匹配阈值 | `threshold` | `0.8` |
| 目标关卡严格匹配阈值 | `threshold` | `0.88` |
| 严格模式边缘匹配阈值 | `edge_threshold` | `0.45` |
| 严格模式左侧重点区域阈值 | `focus_threshold` | `0.82` |
| Canny 低阈值 | `50` | `50` |
| Canny 高阈值 | `150` | `150` |
| 重点区域宽度比例 | `0.62` | `62%` |

## 返回结果

匹配成功返回：

```python
{
    "top_left": max_loc,
    "center": (center_x, center_y),
    "confidence": max_val
}
```

匹配失败返回：

```python
None
```

严格模式下，如果灰度匹配通过，但边缘匹配或重点区域匹配失败，也返回 `None`。

## 可单独测试的代码

保存为 `test_template_match.py` 后运行：

```python
import argparse
import cv2


def find_template(main_img, template_path, threshold=0.8, strict=False, edge_threshold=0.45, focus_threshold=0.82):
    template = cv2.imread(template_path)
    if template is None:
        raise FileNotFoundError(f"找不到模板文件: {template_path}")

    th, tw = template.shape[:2]

    if strict:
        main_match_img = cv2.cvtColor(main_img, cv2.COLOR_BGR2GRAY)
        template_match_img = cv2.cvtColor(template, cv2.COLOR_BGR2GRAY)
    else:
        main_match_img = main_img
        template_match_img = template

    result = cv2.matchTemplate(main_match_img, template_match_img, cv2.TM_CCOEFF_NORMED)
    _, max_val, _, max_loc = cv2.minMaxLoc(result)

    edge_score = None
    focus_score = None

    if max_val >= threshold:
        if strict:
            x, y = max_loc
            gray_patch = main_match_img[y:y + th, x:x + tw]
            if gray_patch.shape[:2] != template_match_img.shape[:2]:
                return None

            patch_edges = cv2.Canny(gray_patch, 50, 150)
            template_edges = cv2.Canny(template_match_img, 50, 150)
            edge_result = cv2.matchTemplate(patch_edges, template_edges, cv2.TM_CCOEFF_NORMED)
            _, edge_score, _, _ = cv2.minMaxLoc(edge_result)

            focus_width = max(1, int(tw * 0.62))
            focus_patch = gray_patch[:, :focus_width]
            focus_template = template_match_img[:, :focus_width]
            focus_result = cv2.matchTemplate(focus_patch, focus_template, cv2.TM_CCOEFF_NORMED)
            _, focus_score, _, _ = cv2.minMaxLoc(focus_result)

            if edge_score < edge_threshold or focus_score < focus_threshold:
                return {
                    "matched": False,
                    "reason": "strict_check_failed",
                    "top_left": max_loc,
                    "confidence": max_val,
                    "edge_score": edge_score,
                    "focus_score": focus_score,
                }

        center_x = max_loc[0] + tw // 2
        center_y = max_loc[1] + th // 2
        return {
            "matched": True,
            "top_left": max_loc,
            "center": (center_x, center_y),
            "confidence": max_val,
            "edge_score": edge_score,
            "focus_score": focus_score,
        }

    return {
        "matched": False,
        "reason": "confidence_below_threshold",
        "top_left": max_loc,
        "confidence": max_val,
        "edge_score": edge_score,
        "focus_score": focus_score,
    }


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--image", required=True, help="待检测的大图路径")
    parser.add_argument("--template", required=True, help="模板图路径")
    parser.add_argument("--threshold", type=float, default=0.8)
    parser.add_argument("--strict", action="store_true")
    parser.add_argument("--edge-threshold", type=float, default=0.45)
    parser.add_argument("--focus-threshold", type=float, default=0.82)
    args = parser.parse_args()

    main_img = cv2.imread(args.image)
    if main_img is None:
        raise FileNotFoundError(f"找不到大图文件: {args.image}")

    result = find_template(
        main_img,
        args.template,
        threshold=args.threshold,
        strict=args.strict,
        edge_threshold=args.edge_threshold,
        focus_threshold=args.focus_threshold,
    )
    print(result)


if __name__ == "__main__":
    main()
```

运行示例：

```powershell
python test_template_match.py --image screenshot.png --template img\30-2_.png --strict --threshold 0.88 --edge-threshold 0.45 --focus-threshold 0.82
```

普通匹配测试：

```powershell
python test_template_match.py --image screenshot.png --template img\jiesuan_.png --threshold 0.8
```
